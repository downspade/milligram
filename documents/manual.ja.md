## はじめに

milligram image viewer はシンプルな画像ビューワです。フレームが無く、機能も見映えもシンプル。内蔵で BMP / JPEG / GIF（アニメ）/ PNG / WebP（アニメ）/ AVIF（アニメ・HDR 対応）/ JpegXL (アニメ) / 各種動画ファイルを表示できます。さらに **Susie プラグイン** を追加すれば、多様な画像形式に対応可能です。**非商用利用時のみフリーウェア** です。

主な特徴：

- スライドショー
- 様々なフルスクリーンモード
- 圧縮フォルダ内の画像閲覧（非圧縮 ZIP はプラグイン無しで表示可能）
- 画像の整理
- 各種設定を切り替えての複数起動（インスタンス）

「デスクトップに画像を常に表示しておきたい」「デスクトップの写真立てのように使いたい」というコンセプトで制作されました。Ctrl + 右クリックでの画像ファイル整理、お気に入りリスト保存などの機能もあります。

## インストール

1. ZIP ファイルを適当な場所に解凍
2. `milligram.exe` を実行
3. ショートカット作成場所を訊かれるので適宜選択
4. BMP 以外を表示したい場合は Susie プラグインを入手し、`milligram.exe` と同じフォルダに `.spi` ファイルを置く（起動時に読み込まれる）

黒い枠内をShift + 右クリック → **オプション → 拡張子の関連づけ** で、ダブルクリックでビューワーを起動できるようになります。

## Susie プラグインについて

Susie プラグインはデフォルトでは `milligram.exe` のあるフォルダを検索する仕様です。他のフォルダにプラグインがある場合は、右クリック → **プラグインのフォルダを指定** でプラグインのファイルを選んでください。そのファイルの存在するフォルダを検索するようになります。

2 つ以上のフォルダを指定するには ini ファイルを直接編集する必要があります。

### Susie 関連リンク

- [Susie の部屋](http://digitalpad.co.jp/~takechin/)
- [Susie プラグインの入手先](http://www.vector.co.jp/vpack/filearea/win95/art/graphics/loader/susie/index.html)
- [TORO's Library](http://www2f.biglobe.ne.jp/~kana/link.html)（x64 バージョンの仕様はこちらに従いました）

> milligram image viewer は、未対応のプラグインがいくつも存在します。

## 使い方

普通に実行します。閲覧したいファイルをウィンドウにドロップしてください。表示可能な画像ファイルであれば、その画像が表示されます。ショートカットにファイルをドロップしても表示可能です。

### 基本操作

- **画像をダブルクリック**：ドロップされたファイルの一覧が表示。表示したいファイルをダブルクリックで表示
- **画像上でホイール**：画像が切り替わります。感度は **オプション → ホイールの感度** から変更可能
- **画像をドラッグ**：タイトルバーが無いので、ウィンドウそのものをドラッグして移動できます
- **表示している大きさを変更**：カーソルを画像の端に動かすとカーソル形状が変わります。そのまま大きさを変更できます。**Alt** ボタンを押しながらドラッグすると、自由な角度に配置できます

### 設定項目

- **プラグインのフォルダを指定**：Susie プラグインの入っているフォルダを指定（2 つ以上は ini を編集）
- **内部ローダー優先ファイル設定**：内部ローダーを優先して読みこむファイルマスクを設定。WebP と GIF アニメーションはアニメーションの関係でここで何を設定しても必ず内部ローダーが優先
- **インスタンス**：設定ファイルや読み込むファイルを複数用意することで、設定の異なるビューワーを同時に動かせる機能。例えば 1 つのインスタンスをロックして特定のフォルダのスライドショーをデスクトップピクチャとして常時表示、もう 1 つは通常のビューワーとして利用、といった使い方が可能

### ファイル整理（Ctrl + 右クリック）

Ctrl キーを押しながら右クリックすると、現在表示中のファイルが圧縮フォルダ内に **無い** 場合に、移動可能なフォルダ名が表示されます。フォルダ名をクリックした時点でファイルがそのフォルダに移動します。

- **Ctrl + フォルダ名クリック**：移動先に同名ファイルがある場合に自動的にリネームして移動
- **Ctrl 無しでフォルダ名クリック**：上書き確認ダイアログ表示

連続してファイルを移動することも可能です。画像ファイルの整理に活用してください。

### 履歴メニューの操作

- **クリック**：その履歴を開く
- **Shift + クリック**：その履歴エントリを削除

履歴の最後のエントリは「履歴をクリア」項目で、すべての履歴を一括削除できます。

## マウス操作

### ファイル操作

- **ファイルのドロップ**：フォルダなら中のファイル、ファイルならそれを表示
- **`Ctrl` + ドロップ**：ファイルリストに追加

### 画像操作

- **ホイール操作**：表示画像の切り替え
- **ホイールクリック**：終了
- **`Ctrl` + ホイール操作** または **右クリック + ホイール操作**：ズームイン / ズームアウト
- **`Ctrl` + ホイールクリック** または **右クリック + ホイールクリック**：等倍で表示
- **`Alt` + ホイール操作** または **左クリック + ホイール操作**：画像の回転
- **`Alt` + ホイールクリック** または **左クリック + ホイールクリック**：回転をリセット
- **`Ctrl` + `Alt` + ホイール操作** または **右クリック + 左クリック + ホイール操作**：ウィンドウの透明度を変更
- **`Ctrl` + `Alt` + ホイールクリック** または **右クリック + 左クリック + ホイールクリック**：不透明度を 100% に
- **`Shift`+** 表示範囲を変更する
- **左クリック + 右クリック**：画像を画面内に収まるように移動
- **Shift + 上記の操作**：画像だけ変更(PeepMode)

## 起動時の操作

- **`Ctrl` を押しながら起動**：「起動時に前回のファイルを読み込む」が指定されていても、ファイルリストを読み込まずに起動
- **`Shift + Ctrl` を押しながら起動**：初期状態で起動（動作がおかしくなったときに試してください）

## 困ったときには？

### 起動しない

「前回のファイルを読み込む」をチェックしている状態で、ファイルに何らかのトラブルがあり、起動時にエラーで落ちてしまうことがあります。次のいずれかを試してください：

1. `Ctrl` を押しながら起動
2. 何らかのファイルをショートカットにドロップして起動
3. `Shift` + `Ctrl` を押しながら起動（初期状態で起動）

### ウィンドウがどこかに行ってしまった

小さい画像を読み込んでいないのにウィンドウが見えないときは、タスクトレイのアイコンを右クリック → **中央に表示** を実行してください。

### それでも表示されない

プラグインなどに問題がある可能性があります。タスクトレイのアイコンを右クリック → **閉じる** を選択して終了後、`Ctrl` + `Shift` を押しながら起動してください。

## その他の機能

`ini` ファイルを編集することで設定を細かく変更できます。`ini` ファイルの場所：

```
C:\Users\(ユーザー名)\AppData\Local\milligram
```

（古い Windows では `C:\Documents and Settings\(ユーザー名)\Local Settings\Application Data\milligram`）
